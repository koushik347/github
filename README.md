# Koushik Reddy Portfolio

## Project files
- `index.html` — website content and structure
- `style.css` — layout, colors, and responsive styling
- `script.js` — mobile navigation and footer year

## Run locally
Keep all three files in the same folder and open `index.html` in your browser.

## Push to GitHub
Run these commands from this folder:

```bash
git init
git add .
git commit -m "Add portfolio website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/koushik-portfolio.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username.

## Deploy with GitHub Pages
In your GitHub repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
